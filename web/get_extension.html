Get Krypton for Chrome

The Chrome extension adds the focus lock (stops endless scrolling on YouTube, Instagram…) and Krypton in your browser toolbar. Works on laptops and PCs with Chrome or Edge — not on phones.

⬇ Download Krypton extension

A small .zip file, already set up for this Krypton site.

Install it (2 minutes)

  1. Open the downloaded krypton-extension.zip → right-click → Extract All → Extract.
  2. In Chrome, open chrome://extensions (copy it into the address bar).
  3. Turn on Developer mode (switch at the top right).
  4. Click Load unpacked → select the krypton-extension folder you extracted.
  5. Click the 🧩 puzzle icon in the toolbar → pin Krypton 💎.
  6. Open Krypton → ⚙️ Settings → 🌐 Krypton server: the link is already filled in — type your username and password → Connect. Done!

Chrome may show a "developer mode extensions" notice when it starts — just close it. Parents set the lock rules at Parent view.
